# 星图增强设计 - 用户交互体验升级

## 概述

将星图面板（starmap.html）升级为系统主入口，增加右侧详情面板，实现「选星体→发指令→看响应」的完整交互闭环，同时补齐 loading/错误提示/日志展示等用户体验基础设施。

## 修改范围

### 文件清单

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `star-ui/pages/starmap.html` | 主要修改 | 左右分栏布局 + 详情面板 4 Tab |
| `star-ui/pages/orbit.html` | 次要修改 | 接收 hash 参数自动选中星体 |
| `star-ui/pages/starlight.html` | 次要修改 | 增加日志来源标签 |
| `star-ui/js/api-bridge.js` | 新增内容 | 日志 API、通知函数、全局状态 |

### 不改的文件

- `star_core/log_reader.py` — 已完善
- `star_core/star_emissary.py` — 已完善
- `star_api/routes/emissary.py` — 日志 API 已完备
- `config.yaml` — 暂时不动
- `scripts/*.ps1` — 暂时不动

## 详细设计

### 1. 星图页布局改造

**当前**：100% 宽度的星体网格，点击"发送指令"跳出到独立页面。

**改造后**：

```
┌──────┬───────────────────┬──────────────────────────┐
│ 侧边栏 │  星体网格(左 60%)  │  详情面板(右 40%)        │
│ 导航   │                   │   position: sticky      │
│ ⭐星图 │  ┌───┐ ┌───┐     │  ┌─ 4 个 Tab ─────────┐ │
│ 🌀星轨 │  │ T │ │ C │     │  │ [信息][指令]       │ │
│ 👁星辉 │  └─ ┘ └─ ┘     │  │ [日志][历史]       │ │
│       │  ┌───┐           │  │                     │ │
│       │  │ W │           │  │ (Tab 内容动态切换)   │ │
│       │  └─ ┘           │  └─────────────────────┘ │
└──────┴───────────────────┴──────────────────────────┘
```

- 点击星体卡片 → 右侧面板显示详情，不跳转页面
- 选中的星体卡片高亮边框
- 小屏幕下面板折叠到底部（通过 toggle 按钮切换）
- 星体卡片上的"发送指令"按钮直接打开详情面板的"指令"Tab

### 2. 详情面板 - 4 个 Tab

#### Tab: 信息

```
┌─ 星体信息 ──────────────────────┐
│ TRAE Work CN                    │
│ PID: 18424   类型: trae         │
│ 状态: 空闲   最后活跃: 10:48    │
│ 响应来源: ⚡ 日志 (10.6ms)      │
│ 日志文件: 258 个               │
│ [查看日志] → 切到日志 Tab       │
└─────────────────────────────────┘
```

数据来源：`emissaryApi.status(starId)` + `emissaryApi.logs(starId)`

#### Tab: 指令

```
┌─ 发送指令 ──────────────────────┐
│ 适配器: [Trae Solo ▼]          │
│ ┌─────────────────────────┐     │
│ │ 输入提示文字…             │     │
│ └─────────────────────────┘     │
│ [⚡ 发送]  [📷 OCR 发送]       │
│                                 │
│ ┌─ 响应结果 ─────────────────┐ │
│ │ 2加3等于5。                 │ │
│ │ 来源: ⚡ 日志 10.6ms       │ │
│ │ 耗时: 0.5s                 │ │
│ │ [复制] [重新发送]          │ │
│ └────────────────────────────┘ │
└─────────────────────────────────┘
```

- **⚡ 发送**：调用 `emissaryApi.ask()`，日志优先 → OCR 兜底
- **📷 OCR 发送**：强制只用 OCR（`emissaryApi.send()` + `emissaryApi.response()` 轮询）
- 发送中按钮变 loading 态
- 响应结果展示来源标签和耗时

### 3. 基础设施

#### 全局通知条

页面顶部固定通知区域，不干扰主要内容：

```javascript
// API
showNotification('指令发送成功', 'success');  // 绿色，3s 消失
showNotification('正在重连…', 'warning');      // 橙色，需手动关闭
showNotification('API 连接失败', 'error');      // 红色，需手动关闭
```

#### 加载状态

- 星体网格加载 → 6 个灰色骨架卡片
- 发送指令 → 按钮显示旋转 SVG 并禁用
- 日志读取 → 区域显示 "读取日志中… (10ms)"

#### 侧边栏导航

- 当前：`<a href="#">` 无反应
- 修复：点击导航项，通过 `location.hash` 切换显示哪个页面
- 选中的星体信息存入 `sessionStorage.selectedStarId`
- 切换到 orbit.html / starlight.html 时读取该值自动选中星体

#### 连接状态指示器

右上角"已连接"指示灯增强：
- 悬浮显示：API 地址、WebSocket 状态、延迟
- 断线自动重连，状态文字变为"重新连接中…"
- 重连成功恢复"已连接"
