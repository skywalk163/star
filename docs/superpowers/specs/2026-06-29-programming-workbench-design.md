# 星际编程工作台 - 产品设计规格

> **版本：** v1.0  
> **日期：** 2026-06-29  
> **产品定位：** AI 效率工具 - 多 AI 并行编程工作台  
> **目标用户：** 使用多个 AI Agent 进行编程开发的个人开发者

---

## 1. 概述

### 1.1 产品愿景

将群星从"AI Agent 管理系统"升级为"多 AI 并行编程工作台"，让开发者能够：
- 同时与多个 AI 协作
- 直观对比不同 AI 的回答
- 高效管理和追踪编程任务

### 1.2 核心价值主张

| 痛点 | 解决方案 |
|------|---------|
| 结果对比麻烦 | 并行对话 + 结果对比视图 |
| 分工不明确 | 任务看板（手动分配） |
| 上下文丢失 | 项目上下文共享 |
| 状态不透明 | 实时任务状态流 |

### 1.3 设计原则

- **效率优先**：减少操作步骤，一键直达
- **信息密度**：单屏展示更多内容，减少切换
- **渐进披露**：高级功能按需展示
- **一致性**：与现有群星风格保持统一

## 2. 功能模块

### 2.1 并行编程工作台（核心页面）

**路径：** `/ui/pages/programming.html`

#### 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│  [项目选择 ▼]  [上下文卡]  [新建任务]           [对比模式] [设置] │
├────────────────┬──────────────────────────────────────────────────┤
│                │                                                  │
│   任务列表      │              编程工作区                          │
│   (200px)      │                                                  │
│                │   ┌─────────────────────────────────────────┐   │
│  ┌──────────┐  │   │  任务标题                    [AI-A] [AI-B]│   │
│  │ 任务卡片  │  │   ├─────────────────────────────────────────┤   │
│  │ 待办/进行 │  │   │                                         │   │
│  └──────────┘  │   │   AI-A 的回答                            │   │
│                │   │   ─────────────────                       │   │
│  ┌──────────┐  │   │                                         │   │
│  │ 任务卡片  │  │   │   AI-B 的回答                            │   │
│  │ 已完成    │  │   │                                         │   │
│  └──────────┘  │   │                                         │   │
│                │   └─────────────────────────────────────────┘   │
│                │                                                  │
├────────────────┴──────────────────────────────────────────────────┤
│  [AI-A: 就绪]  [AI-B: 工作中...]  [Dumate: 空闲]  [+ 添加AI]       │
└─────────────────────────────────────────────────────────────────┘
```

#### 功能点

1. **任务管理**
   - 创建新任务（输入标题 + 可选描述）
   - 任务状态：待办 → 进行中 → 已完成
   - 拖拽排序
   - 删除任务

2. **AI 分配**
   - 从底部 AI 列表拖拽到任务卡片
   - 一个任务可分配多个 AI
   - 点击任务显示分配详情

3. **编程工作区**
   - 显示任务标题和描述
   - 显示分配的所有 AI 对话
   - 支持发送指令到所有分配的 AI
   - 支持查看历史对话

4. **项目上下文卡**
   - 读取当前打开的文件
   - 读取项目结构（可选）
   - 一键复制上下文到剪贴板
   - 支持插入到指令中

### 2.2 结果对比视图

**入口：** 点击任务卡片的"对比"按钮

```
┌─────────────────────────────────────────────────────────────────┐

│  ┌─────────────────────────────────────────────────────────┐   │
```

#### 功能点

1. **并排对比**

2. **差异高亮**
   - 自动检测内容差异
   - 高亮显示不同部分
   - 快速跳转差异点

3. **操作**
   - 复制选中内容
   - 插入到当前编辑器
   - 导出对比结果

## 3. 数据模型

### 3.1 任务 (Task)

```typescript
interface Task {
  id: string;                    // UUID
  title: string;                 // 任务标题
  description?: string;           // 任务描述
  status: 'todo' | 'in_progress' | 'done';
  assignedAIs: string[];         // 分配的 AI ID 列表
  createdAt: string;             // ISO 时间
  updatedAt: string;
  context?: string;              // 项目上下文
}
```

### 3.2 AI 对话记录 (AIDialog)

```typescript
interface AIDialog {
  id: string;
  taskId: string;
  aiId: string;                  // AI 标识 (trae, dumate, codearts)
  messages: DialogMessage[];
}

interface DialogMessage {
  role: 'user' | 'assistant';
  content: string;
  timestamp: string;
}
```

### 3.3 存储

- **本地存储**：localStorage
- **数据结构**：
  - `star_programming_tasks`：任务列表
  - `star_programming_dialogs`：对话记录
  - `star_programming_contexts`：保存的上下文

## 4. 交互设计

### 4.1 核心流程

#### 创建并执行任务

```
1. 点击 [+ 新建任务]
2. 输入任务标题
3. （可选）输入描述
4. 从底部 AI 列表拖拽到任务卡片
5. 点击任务卡片进入工作区
6. 输入指令，点击发送
7. 等待多个 AI 返回结果
8. （可选）点击对比查看结果
9. 选择合适的方案
10. 拖拽任务到"已完成"
```

### 4.2 快捷操作

| 操作 | 快捷键 |
|------|--------|
| 新建任务 | Ctrl/Cmd + N |
| 发送指令 | Ctrl/Cmd + Enter |
| 切换对比模式 | Ctrl/Cmd + D |
| 快速复制上下文 | Ctrl/Cmd + Shift + C |

### 4.3 状态反馈

- **AI 就绪**：绿色圆点
- **AI 工作中的**：橙色圆点 + 脉冲动画
- **AI 空闲**：灰色圆点
- **任务有新消息**：任务卡片右上角小红点

## 5. 技术实现

### 5.1 前端

- **页面**：`star-ui/pages/programming.html`
- **服务**：
  - `star-ui/js/programming-store.js` - 状态管理
  - `star-ui/js/context-reader.js` - 上下文读取
- **依赖**：
  - 复用现有 API（stars/status, broadcast/send）
  - 复用 template-service.js

### 5.2 API 扩展

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/programming/tasks` | GET | 获取任务列表 |
| `/api/programming/tasks` | POST | 创建任务 |
| `/api/programming/tasks/{id}` | PUT | 更新任务 |
| `/api/programming/tasks/{id}` | DELETE | 删除任务 |
| `/api/programming/context` | GET | 获取项目上下文 |
| `/api/programming/compare` | POST | 对比多个 AI 回答 |

### 5.3 项目上下文读取

- 读取当前打开文件（通过窗口标题）
- 读取项目根目录结构（可选）
- 生成上下文摘要
