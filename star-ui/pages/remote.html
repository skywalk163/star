◆ 快速上手
1. 选择窗口 — 在左侧星体列表中点击一个窗口
2. 查看截图 — 主区域实时显示窗口画面，自动定时刷新
3. 点击热点 — 显示预设热点区域，点击即可打开指令输入框
4. 发送指令 — 输入内容后自动发送到 AI 对话输入框
◆ 快捷键参考
Ctrl+Tab
切换到下一个标签页
Ctrl+Shift+Tab
切换到上一个标签页
Ctrl+Enter
发送指令（在指令输入框中）
Esc
关闭当前弹窗
◆ 功能说明
热点
显示预设的 AI 界面操作区域（如输入框、发送按钮），点击即可发送指令。
校准
通过 OCR 自动识别窗口中的输入框位置，校准热点坐标。适用于布局变化后的重新定位。
键盘
模拟键盘操作：快捷热键、自定义组合键、直接文本输入、操作序列（JSON）。
标签切换
在 AI 软件的多个标签页之间切换。也可点击截图顶部的标签区域直接切换。
认证
设置 API Key 以访问受保护的远程控制服务。admin 角色完全控制，viewer 角色只读查看。
◆ 热点校准说明
1. 选择目标窗口，确保输入框在画面中可见
2. 点击 校准 按钮启动 OCR 识别
3. 系统自动扫描窗口，识别可能的输入框位置
4. 校准结果会显示找到的候选数量，热点自动更新
5. 校准后点击 显示热点 查看识别结果
6. 若不满意，调整窗口布局后重新校准
